Se connecter
Connexion via WebSocket securise (wss://host:8884/mqtt) - le port 8884 est fixe cote navigateur, meme si le tracker utilise 8883 de son cote. Ces identifiants sont ceux deja saisis sur le tracker (portail telephone ou Sans-fil > Menu MQTT) - rien n'est enregistre dans ce navigateur, a ressaisir a chaque ouverture si tu n'utilises pas le lien/QR complet genere par le tracker.
Le jeton distant est optionnel : sans session Admin/Root active sur CETTE page (il n'y en a jamais depuis un navigateur), il est INDISPENSABLE pour que RAZ AZ/RAZ TILT/SECU (repli) soient acceptees - inutile pour Auto/Manuel/axe/jog/nuit/offsets LDR qui restent libres. Arme/change-le au tracker via {"cmd":"set_remote_token","token":"..."} depuis une session Admin/Root reelle (Admin > Administration).
Aide
Touche ou survole un bouton de l'ecran ci-dessus (colonnes, fleches, ARRET D'URGENCE) pour voir ici ce qu'il fait exactement, avant de l'utiliser.
Ecran interactif : tape AUTO/MANU/AXE/RAZ/SECU/NUIT/EXIT dans les colonnes, ou les fleches/STOP en mode Manu - memes commandes que l'ecran local.
